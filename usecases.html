Managing the common use case library — how this works ▼

This is the master library of common analytical use cases consultants can drop into any client assessment. Edits here appear as the picker chips on every new assessment's Use Cases tab, and refresh live on any open assessment.

  • Edit in place — click a title or description to rewrite it. Changes autosave.
  • Map capabilities — + Capability opens a picker grouped by pillar. These pre-selections seed each use case when a consultant adds it to an assessment; the consultant can still refine per client.
  • Add or remove — + Add use case creates a blank entry; the × on a card removes it. Removing a library entry does not touch use cases already captured in existing assessments.
  • Seed items are labelled seed; feel free to edit or delete them.
  • Saving — every change autosaves alongside the rubric and syncs live to anyone else editing.

About the use case library

The library is a shortlist of the analytical outcomes clients most often ask for — cross-channel attribution, retention analysis, consent-compliant measurement and so on — pre-mapped to the capabilities that typically deliver them. Consultants use it as a scaffolding: drop the relevant items into the assessment, rewrite them for the client's specific situation, and use the pre-mapped capabilities as a starting point for the prioritization conversation.

The library is stored alongside the master rubric. Edits here apply to every future assessment and refresh live on any open assessment. Existing use cases already captured in assessments are independent copies and are not modified retroactively.
